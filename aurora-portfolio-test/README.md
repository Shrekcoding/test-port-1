# Singel Cell Productions — Animated Aurora Portfolio Demo

## Test it
1. Unzip the archive.
2. Open `index.html` in Chrome, Firefox, or Edge. No build tools, server, or dependencies required.
3. Use the bottom-right speed slider or Pause button to test the aurora.

## Add your actual images
The included SVG project thumbnails are **illustrative placeholders**, not your real artwork. Place your own PNG/JPG/WebP files in `images/` and edit the `projects` array at the top of `script.js` to point to them. Update project titles and categories there too.

## Customize
- Colors and layout: `styles.css`
- Aurora colors, movement, and speed: `script.js`, look for `colors`, `wave`, and `speed`.
- Text and sections: `index.html`
- Replace `hello@example.com` with your real contact address.

## Notes
This is a standalone HTML/CSS/Canvas demo inspired by the requested dark aurora portfolio aesthetic, not a copy of the linked tutorial or your live site's source code. The aurora is animated using the Canvas API (no external library), and it respects reduced-motion settings. Google Fonts require an internet connection; system fonts work offline.
